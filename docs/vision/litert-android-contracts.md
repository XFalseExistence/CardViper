# Android LiteRT contract scaffold

`LiteRtModelContract` is a strict reader for normalized Android runtime contracts. Version 1 accepts only declared fields and supported enum values; missing or unknown values fail closed. Contract fixtures are synthetic and live under Android test resources with `TEST_ONLY`, `SYNTHETIC`, and `NOT_PRODUCTION_CONTRACT` in their names. They must never be copied into app assets.

The shared contract declares a SHA-256 artifact digest, one rank-four input tensor (`NHWC` or `NCHW`, batch one, three channels), its `FLOAT32` or `UINT8` dtype, contract-owned channel order, resize policy and filter, affine pixel transform (`pixel * scale + offset`), padding byte, and output tensor names/shapes/dtypes. Runtime outputs currently support `FLOAT32` only. Classifier contracts declare exactly 53 codec-valid labels in output-index order, `BACK` at index 52, the labels-file digest, probability score semantics, and `top_k` including the best result. Detector contracts declare only `CARD`, output tensor roles, coordinate order and units, optional count tensor, NMS ownership, and score/IoU thresholds.

Letterbox box transforms use continuous edge coordinates and the same scale/padding equations as `ml/cardviper_ml/detector_geometry.py`. Pixel resizing uses center-based nearest or bilinear sampling; a contract chooses the filter. Host NMS is deterministic, descending by score with original output order as the tie-break. The parser and pure postprocessors do not imply that the current random-weight detector smoke established production semantics.

The parser's normalized Android schema is an integration boundary, not a generated model contract. A future export bridge must translate the selected, evaluated B2/B3 artifact metadata into this format and provide the actual preprocessing, tensor metadata, coordinate convention, NMS ownership, and hashes. Until then, `app/src/main/assets/vision` contains no production model or contract, no LiteRT Android runtime is linked, and `CardViperApplication` keeps its unavailable detector and no-op recognizer.
